# Working in pdt-anes-cdf

This repo holds ANES CDF metadata built to the PublicDataToolkit standard (`../PublicDataToolkit/STANDARD.md`).

- `metadata/` and `build/report.md` are generated by `build/build_slice.py`. Don't edit them; change the build or `build/slice.yaml`.
- `dataset.yaml`, `sources.yaml`, `EXTENSIONS.md` and `build/slice.yaml` are edited by hand.
- `data/` is gitignored and never committed.
- Run `make build` then `make check` (the CultureWar conda env works).
- The ANES terms are in `dataset.yaml` (reviewed by Allen, 2026-11-19). Anything published must cite ANES and link back to the original dataset.
